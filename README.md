# Localização Brasil no SAP ERP

Apostila de treinamento que reorganiza a árvore **Brasil → Funções válidas para várias aplicações → Funções gerais**
do SAP Help Portal em 16 módulos didáticos, cobrindo os 99 tópicos da documentação.

- 99 tópicos · 16 módulos · 83 novos · 15 modificados · 1 eliminado
- Busca por campo, transação, nota SAP ou tabela
- Filtros por tipo de mudança e por trilha (consultor, fiscal, key user, técnico)

Página estática única (`index.html`), sem build. Publicada no Vercel.

## Fonte

Conteúdo extraído de *O que há de novo para localizações funcionais no SAP ERP*
(SAP Help Portal, pt-BR). As notas SAP citadas apontam para o SAP for Me e exigem login.
